# 立体诊断图备用素材

页面使用原 `state_picture` 下的立体图，保留原始 1280×698 画布与透明背景；状态引线独立绘制。备用图不自动替换主图。

- `powder.png`：铺粉系统红色高亮。
- `optics.png`：光学系统红色高亮。
- 同名 SVG 是 1280×698 的等比例展示入口，PNG 保留生成原始分辨率与透明通道。

生成方式：内置 image_gen，以 `power_off.png` 为编辑参考。生成图可能有细微几何差异，因此严格一致的主图仍使用原始素材。

提示词：保留原图半透明机壳、灰色工业立体剖视风格、机器结构、视角、构图和主体比例；仅将粉末输送/铺粉机构（powder）或顶部激光源/扫描头（optics）改为克制的红色；透明背景，无文字、引线、面板、地面或外部阴影，单台整机；目标画布1280×698。
