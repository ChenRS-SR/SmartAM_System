# 新版立体诊断素材

通过内置 image_gen 参考 `../spares/powder.png` 制作；`laser.png` 复用已确认的 `../spares/optics.png`。原始旧版素材仍保留在上级目录。

全部 PNG 为透明背景，保持同一整机视角和构图；前端统一以 1280×698 逻辑画布等比例显示，不拉伸。原始生成分辨率保留。AI 生成图存在细微结构差异，用于功能定位示意，不代表设备实测机械结构。文字、引线和状态标识由代码叠加。

| 文件 | 用途 |
| --- | --- |
| neutral.png | 中性整机／数据未接入 |
| healthy.png | 已确认健康 |
| scraper.png | 刮刀扭矩故障 |
| feeder.png | 落粉轴扭矩故障 |
| laser.png | 激光器故障 |
| filter.png | 滤芯压力过大 |
| gas.png | 气源压力故障 |
| fan.png | 风机转速过高 |
| chiller.png | 水冷机故障 |
| equipment.png | 设备问题总览，未指定或多个部件，具体类别见引线和详情 |
| process.png | 工艺问题，仅强调成形区能量分布 |

单一明确故障按类别选图；多故障使用设备问题总览并在部件详情逐项展示。未分类的设备异常不擅自映射某个部件。工艺问题不渲染设备部件故障。素材不改变诊断结果。完整生成提示词见 `prompts.json`。
