# 课题四接口协议

以下四节续接原协议第 3 章。服务地址为 `http://<部署电脑IP>:<实际端口>`，当前默认端口为 `8001`。请求与返回均为 JSON，设置 `Content-Type: application/json`。

统一返回：`{"status":200,"message":"操作成功","data":{...}}`。失败时 `data` 为 `null`，HTTP 状态码与 `status` 一致：400 参数错误、404 数据不存在、409 状态或编号冲突、503 真实处理不可用、500 服务错误。下面返回示例仅列主要字段。

当前回放画面导出：在闭环调控页点击“导出当前接口数据”，下载四接口结果 JSON。程序固定点击时的设备、层号和游标。外部调用须传入同一 `offset`；不传游标不会自动跟随某个浏览器。

## 3.23 增材制造制件缺陷关联异常识别

接口名：`/api/task4/defect-recognition`

协议：http

调用方式：POST

功能说明：读取指定设备、任务和层的缺陷识别、关联归因结果，也可选择真实模型处理。

**请求参数**

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| deviceId | String | 是 | 设备编号，如 `slm-b44` |
| taskId | String | 否 | 任务编号，省略时使用设备绑定案例 |
| layerNo | Integer | 否 | 层号；省略时使用默认播放起点所在层 |
| offset | Number | 否 | 案例游标，单位 s；提供时只返回该时刻已到达的本层结果 |
| processingMode | String | 否 | `archive`：封存结果（默认）；`real`：真实处理 |
| resultScope | String | 否 | `layer`（默认）读取本层；`display` 读取当前画面，须提供 offset，recognition/trace 各自保留实际层号 |

**返回字段（data）**

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| deviceId / taskId / layerNo | String / String / Integer | 是 | 结果对应设备、任务、层 |
| ready | Boolean | 是 | 本层识别结果是否可用 |
| source | String | 是 | `sealed-model-results`、`model-runtime`、`saved-inference` 或 `device-record` |
| recognition | Object/null | 是 | 识别结果；`label` 为标签，`prob.proc/dev` 为工艺/设备问题概率（0～1），`image.url` 为图像地址；display 模式保留页面原字段（B17 为 def/vis/tq） |
| trace | Object/null | 是 | 溯源结果；`conclusion` 为诊断结论，`factors.proc/dev` 为两侧贡献，`actions` 为检查建议 |

请求示例：

```json
{"deviceId":"slm-b44","layerNo":8,"processingMode":"archive"}
```

返回示例：

```json
{"status":200,"message":"操作成功","data":{"deviceId":"slm-b44","taskId":"B44-20250321-09-20","layerNo":8,"ready":true,"source":"sealed-model-results","recognition":{"label":"正常","prob":{"proc":0.1912618583436002,"dev":0.00004848960855318947}},"trace":{"conclusion":"未见异常"}}}
```

仅有故障档案的设备返回 `source=device-record`、`ready=false`，并提供 `diagnosis/advice`，不生成模型概率。新采集任务须先通过现有 `/api/slm/analysis/devices/{deviceId}/layers` 接入处理，再用 `taskId + layerNo` 查询保存结果；`real` 当前用于绑定案例的模型输入。

## 3.24 增材制造制件质量闭环调控与修复

接口名：`/api/task4/quality-control`

协议：http

调用方式：POST

功能说明：按当前切片区域生成调控参数，保存、查询或模拟调控与修复方案。

**请求参数**

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| deviceId | String | 是 | 设备编号 |
| taskId / layerNo / offset / processingMode | 同 3.23 | 否 | 指定分析数据；新任务须已登记对应切片区域 |
| operation | String | 否 | `preview` 预览（默认）、`save` 保存、`get` 查询、`simulate` 模拟 |
| regionIds | Array[String] | 否 | 切片区域编号，如 `region-1`；省略时选择当前全部区域 |
| currentParameters | Object | 否 | 当前参数，见下表；省略字段读取平台配置默认值 |
| strategy | String | 否 | `adjust` 参数调整、`remelt` 重熔、`recoat` 重铺粉、`stop` 停机调整；预览省略时读取各区域当前策略（未设置为 adjust） |
| automatic | Boolean | 否 | 默认 true；false 时参数调整保持基准 |
| requestId | String | 保存时必填 | 请求编号；同设备同编号同内容重复保存返回原方案 |
| planId | String | 查询/模拟时必填 | 已保存方案编号 |

| currentParameters 字段 | 类型 | 默认值 | 单位及范围 |
| --- | --- | --- | --- |
| laserPower | Number | 200 | W，50～500 |
| fillSpeed | Number | 1000 | mm/s，100～5000 |
| layerWaitTime | Number | 2 | s，0～600 |

**返回字段（data）**

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| deviceId / taskId / layerNo | String / String/null / Integer/null | 是 | 对应设备、任务、层；档案设备无逐层任务 |
| planId | String/null | 是 | 方案编号；预览不保存，为 null |
| state | String | 是 | `preview`、`planned`、`simulated` |
| executed | Boolean | 是 | 是否已由真机执行；当前为 false |
| strategy / image | String | 是 | 策略类型（区域不同为 mixed）/ 当前区域标注图地址 |
| regions | Array[Object] | 是 | 每项含 `regionId/name/color/currentParameters/controlParameters/status/strategy/automatic/activePlanId` |
| units | Object | 是 | 三项参数对应单位 |

请求示例：

```json
{"deviceId":"huake-slm-02","operation":"preview","strategy":"adjust","regionIds":["region-1"],"currentParameters":{"laserPower":200,"fillSpeed":1000,"layerWaitTime":2}}
```

返回示例：

```json
{"status":200,"message":"操作成功","data":{"deviceId":"huake-slm-02","planId":null,"state":"preview","executed":false,"strategy":"adjust","regions":[{"regionId":"region-1","name":"区域1","currentParameters":{"laserPower":200,"fillSpeed":1000,"layerWaitTime":2},"controlParameters":{"laserPower":180,"fillSpeed":1000,"layerWaitTime":2},"status":"预计降低输入能量"}]}}
```

保存时改为 `operation=save` 并增加 `requestId`；获得 `planId` 后，使用 `{"deviceId":"huake-slm-02","operation":"simulate","planId":"实际方案编号"}` 模拟。模拟后按设备、任务、区域保存当前策略；2/3/4 替代该区域策略1，其他区域不变。再次保存并模拟 adjust 可恢复策略1；重复模拟旧方案不会覆盖后来选定的策略。当前尚无真机执行器，`operation=execute` 返回 409。区域调控为既定规则自动示意，不是独立区域模型预测。

## 3.25 增材制造装备群运行监测与故障诊断

接口名：`/api/task4/equipment-diagnosis`

协议：http

调用方式：POST

功能说明：批量读取设备状态、运行参数、故障诊断及检查建议。

**请求参数**

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| deviceIds | Array[String] | 否 | 设备编号列表；省略时查询全部设备 |
| offset | Number | 否 | 各案例的查询游标（s）；省略时各用默认起点，档案设备不使用游标 |
| resultScope | String | 否 | `layer`（默认）/ `display`，同 3.23 |
| processingMode | String | 否 | `archive`（默认）/ `real`，同 3.23 |
| parameterSource | String | 否 | `archive`（默认）读取案例/档案参数；`live` 读取实时接入流，未接入返回 404 |

**返回字段（data）**

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| deviceCount / faultDeviceCount | Integer | 是 | 查询设备数 / 已登记故障设备数 |
| devices | Array[Object] | 是 | 设备结果列表 |
| devices[].deviceId / name / source | String | 是 | 设备编号、名称、数据来源 |
| devices[].status | String | 是 | `normal` 正常、`fault` 档案故障、`abnormal` 模型异常、`review` 待复核、`unknown` 未知 |
| devices[].parameters | Array[Object] | 是 | 运行参数，含参数名、值和单位 |
| devices[].diagnosis / advice | String / Array[String] | 是 | 诊断结论 / 检查建议 |
| devices[].offset / time / alarms | Number / String / Array | 否 | 案例游标、数据时间、当前报警（案例设备返回） |
| devices[].recognition / trace | Object/null | 是 | 关联识别与溯源结果，结构同 3.23 |

按画面导出示例：`{"deviceIds":["slm-b44"],"offset":1317,"resultScope":"display"}`，返回该游标对应的参数值及单位。实时流示例：`{"deviceIds":["slm-b44"],"parameterSource":"live"}`；实时结果不混入案例识别或历史溯源。

请求示例：

```json
{"deviceIds":["slm-b17"]}
```

返回示例：

```json
{"status":200,"message":"操作成功","data":{"deviceCount":1,"faultDeviceCount":1,"devices":[{"deviceId":"slm-b17","name":"铂力特 S430 B17","status":"fault","diagnosis":"落粉轴故障","advice":["检查铺粉机构、落粉轴与扭矩状态，确认供粉及运动恢复后继续。"]}]}}
```

## 3.26 增材制造装备群智能运维及故障率统计

接口名：`/api/task4/maintenance-statistics`

协议：http

调用方式：POST

功能说明：查询维护建议、维护记录及故障率，也支持登记任务结果与维护事件。

**请求参数**

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| operation | String | 否 | `query` 查询（默认）、`recordTask` 登记任务结果、`recordMaintenance` 登记维护 |
| deviceIds | Array[String] | 否 | 查询范围，省略为全部设备 |
| startTime / endTime | String | 否 | 同时提供，ISO 8601 含时区；统计区间为 `[startTime,endTime)`，省略为全部登记历史 |
| deviceId / occurredAt | String | 登记时必填 | 单台设备编号 / 任务完成或维护时间，含时区 |
| taskId / faulted | String / Boolean | 登记任务时必填 | 唯一任务编号 / 是否发生设备故障 |
| recordId / description | String | 登记维护时必填 | 唯一维护编号 / 维护内容 |

**返回字段（data）**

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| deviceCount / faultDeviceCount | Integer | 是 | 选定设备数 / 当前档案故障设备数，不受统计时段影响 |
| faultDeviceRatio | Number/null | 是 | 当前档案故障设备数 ÷ 设备数 |
| totalTasks / faultTasks | Integer | 是 | 区间内登记任务数 / 故障任务数 |
| taskFaultRate | Number/null | 是 | 故障任务数 ÷ 登记任务数，0～1；无任务时为 null |
| maintenanceCount | Integer | 是 | 区间内维护记录数 |
| records | Array[Object] | 是 | `deviceId/recordId/occurredAt/description` |
| advice | Array[Object] | 是 | `deviceId/diagnosis/suggestion` |

请求示例：

```json
{"operation":"query","deviceIds":["slm-b44"],"startTime":"2026-11-23T00:00:00+08:00","endTime":"2026-11-24T00:00:00+08:00"}
```

返回示例（尚无登记任务或维护记录）：

```json
{"status":200,"message":"操作成功","data":{"deviceCount":1,"faultDeviceCount":0,"faultDeviceRatio":0,"totalTasks":0,"faultTasks":0,"taskFaultRate":null,"maintenanceCount":0,"records":[],"advice":[]}}
```

登记任务示例：`{"operation":"recordTask","deviceId":"slm-b44","taskId":"T001","occurredAt":"2026-11-23T10:00:00+08:00","faulted":true}`。同设备同编号重复登记不重复计数，内容冲突返回 409；模拟调控不会计作维护事件。登记操作返回该设备统计。
